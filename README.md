# شبیه‌ساز مسئله فروشنده دوره‌گرد با سیستم مورچگان

پروژه آموزشی درس طراحی الگوریتم پیشرفته؛ React 19، Vite 7، JavaScript، Tailwind CSS 4، SVG و فونت محلی وزیرمتن. بدون سرور، پایگاه داده یا API خارجی.

## نصب و اجرا

Node.js 22.12 یا جدیدتر (شاخه LTS مانند 24 پیشنهاد می‌شود؛ Vite 7 با Node.js 20.19+ در شاخه 20 نیز سازگار است). فایل ZIP را استخراج و پوشه پروژه را در VS Code باز کنید:

```sh
npm install
npm run dev
```

آدرس نمایش‌داده‌شده در ترمینال را باز کنید (معمولاً http://localhost:5173). بعد از نصب بسته‌ها، کارکرد برنامه به اینترنت وابسته نیست. پیوند منابع علمی فقط برای مطالعه اختیاری بیرونی است.

```sh
npm test
npm run build
npm run preview
```

تست‌های الگوریتم با Node.js Test Runner هستند و حتی بدون نصب کتابخانه‌های رابط کاربری اجرا می‌شوند. اگر مرورگر اجازه تمام‌صفحه نداد، از حالت ارائه داخل همان پنجره استفاده کنید.

## اجرا با Docker

با نصب Docker و افزونه Docker Compose، از پوشه پروژه اجرا کنید:

```sh
docker compose up --build -d
```

برنامه در http://localhost:8080 در دسترس است. ساخت چندمرحله‌ای ابتدا با Node.js 24 و `npm ci` خروجی تولید را می‌سازد و سپس فقط فایل‌های خروجی را با Nginx ارائه می‌کند. برای اعمال تغییرات کد، دستور بالا را دوباره اجرا کنید.

```sh
docker compose down
```

بدون Compose نیز می‌توانید تصویر را بسازید و اجرا کنید:

```sh
docker build -t tsp-aco-frontend .
docker run --rm -p 8080:80 tsp-aco-frontend
```

## راهنمای استفاده

- شش بخش از نوار سمت راست یا دکمه‌های پایین قابل انتخاب‌اند. در حالت ارائه نوار کنار حذف می‌شود، تایمر آغاز می‌شود و حرکت بین صفحات دستی می‌ماند.
- کلید ← یا PageDown برای بخش بعد، → یا PageUp برای بخش قبل. هنگام کار با فیلدها و اسلایدرها این کلیدها مسیر صفحه را عوض نمی‌کنند.
- شبیه‌سازی: مرحله بعد = یک رویداد آموزشی، تکرار بعدی = تا پایان تکرار جاری، اجرای کامل = تمام تکرارها بدون انتظار. اجرای خودکار با توقف/ادامه قابل کنترل است. با تغییر صفحه اجرای خودکار متوقف می‌شود ولی وضعیت باقی می‌ماند.
- پارامترهای محاسباتی پس از شروع قفل می‌شوند؛ «شروع مجدد» قفل را باز می‌کند. بذر پیش‌فرض 42. داده پنج شهر ثابت و تمام هزینه‌ها از ماتریس واقعی هستند.
- نمودار همگرایی از تاریخچه واقعی ساخته می‌شود؛ یک خط تخت نیز معتبر است. نمایش مفهومی مورچه‌های طبیعی در بخش ۲ مستقل از موتور الگوریتم است.
- در صفحه ریاضی و تحلیل، برای مطالعه توضیحات تکمیلی می‌توان پایین صفحه رفت. در ارائه روی بخش‌های اصلی تمرکز کنید.

## ساختار

`src/pages` شش صفحه؛ `src/components` گراف، ماتریس، جدول احتمال و شبه‌کد؛ `src/algorithms` داده مشترک و الگوریتم‌های مستقل؛ `src/hooks/useSimulation.js` اتصال اجرای الگوریتم به React؛ `PRESENTATION.md` متن ارائه.

## مبنای علمی

Ant System (ant-cycle) طبق Dorigo, Maniezzo & Colorni (1996), DOI: https://doi.org/10.1109/3477.484436. نماد ρ در این پروژه نرخ تبخیر است (برخلاف قرارداد ضریب ماندگاری مقاله اصلی). همه مورچه‌ها با فرومون ثابت همان تکرار مسیر می‌سازند. پس از تکمیل همه مسیرها، تبخیر و سپس رسوب Q/L انجام می‌شود. فرومون متقارن است. بهترین جواب سراسری تنها در صورت بهبود جایگزین می‌شود. انتخاب تصادفی با Mulberry32 و محاسبه احتمال مشترک انجام می‌شود. بهینگی عمومی تضمین نمی‌شود.

منابع فنی: https://v7.vite.dev/guide/ ، https://tailwindcss.com/docs/installation/using-vite ، https://fontsource.org/fonts/vazirmatn/use

## اعتبارسنجی

با `npm test` تست‌های مستقل الگوریتم و با `npm run build` ساخت نسخه تولید بررسی می‌شوند. فایل `package-lock.json` در پروژه موجود است و ساخت Docker برای نصب تکرارپذیر وابستگی‌ها از `npm ci` استفاده می‌کند.
